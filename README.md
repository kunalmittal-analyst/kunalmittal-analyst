### 🇮🇳 2. CPI Inflation Case Study | Economic Data Analysis

An analytical case study exploring India's Consumer Price Index (CPI) and the role different consumption categories play in understanding price changes over time.

**Key Questions Explored**
- How does inflation vary across different CPI categories?
- Why can food and cereals have an important influence on household inflation?
- How do categories such as recreation and amusement compare with essential goods?
- How should missing observations be handled without distorting the analysis?

**Analytical Approach**
- Examined CPI category data and trends over time.
- Identified missing values and considered suitable imputation techniques where justified.
- Explored moving averages as a potential method for handling missing observations.


**Skills Demonstrated:** Data Cleaning, Missing-Value Treatment, Trend Analysis, Economic Data Interpretation, Excel
